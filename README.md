# Portfolio

A personal portfolio site built with TanStack Start, React, TypeScript, and Tailwind CSS.

## Development

```sh
npm install
npm run dev
```

## Scripts

- `dev` — start the local development server
- `build` — build for production
- `preview` — preview the production build
- `lint` — run ESLint
- `format` — format files with Prettier

## Stack

- TanStack Start
- TanStack Router
- React
- TypeScript
- Tailwind CSS
